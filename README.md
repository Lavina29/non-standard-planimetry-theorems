# Застосування нестандартних планіметричних теорем у задачах

Науково-дослідницька робота для Малої академії наук України (МАН), секція «Математика», 2025.
**Результат:** _[2 місце на ІІ етапі]_

> **English summary.** A study of non-standard planimetry theorems (Butterfly theorem, Fermat–Torricelli point, Euler line, nine-point circle): proofs and original problems solved with them, including a coordinate-geometry and a stereometry problem.

## Про що робота

Розглянуто чотири «нестандартні» теореми шкільної планіметрії, наведено їхні доведення та розв'язано авторські задачі.

| Теорема | Задача в роботі |
|---|---|
| Теорема Метелика | площа трикутника у вписаній трапеції |
| Теорема Ферма–Торрічеллі | площа перетину двох кіл |
| Лінія Ейлера | рівняння лінії Ейлера за координатами вершин |
| Коло дев'яти точок (коло Ейлера) | відношення об'ємів сфер у піраміді |

У висновках розглянуто можливе застосування в архітектурі, будівництві та логістиці.
